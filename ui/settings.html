alice 设置

语音与缩放保存后立刻生效；端口、对话命令下次启动生效。

快速上手

桌宠默认就能用：监听 Codex 会话日志、播放动画、接受点击对话。 想让它开口说话，在下面「声音」里选一个语音服务、填上 API key，点「试听」—— 试听通过后点「保存」即可。

  1. 选语音服务（MiniMax / OpenAI 兼容 / 本机离线都行）
  2. 填 API key，或留空改用环境变量
  3. 点「试听」确认能出声 → 点「保存」

不想折腾云端？选「本机 SAPI」完全离线，但需要系统里装了中文语音包， 否则读中文不出声（不会用男声顶替）。
